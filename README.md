# lnostbakken.github.io — Website Maintenance Guide

The website is built with [Quarto](https://quarto.org/) and published automatically to GitHub Pages via GitHub Actions. Pushing updated source files to the `main` branch triggers a rebuild and deployment.

---

## What file to edit for each type of update

| What you want to change | File to edit |
|:--|:--|
| Home page text | `index.qmd` |
| About page bio | `about.qmd` |
| CV page (positions, committees, etc.) | `cv.qmd` |
| CV PDF download | Replace `files/CV.pdf` |
| Working papers | `papers_all.bib` — tag with `keywords = {workingpaper}` |
| Publications | `papers_all.bib` — tag with `keywords = {international}` |
| Selected publications (shown in full on Research page) | `papers_all.bib` — tag with `keywords = {international, selected}` |
| Norwegian-language papers (hidden from site) | `papers_all.bib` — tag with `keywords = {norwegian}` |

---

## How to update content

### 1. Edit the relevant file(s)

For most text changes, open the `.qmd` file and edit directly.

For paper updates in `papers_all.bib`:
- **New working paper**: add a `@techreport` entry with `keywords = {workingpaper}`
- **Paper accepted/published**: change the entry type to `@article`, add journal/volume/pages/doi, and change `keywords` from `workingpaper` to `international` (add `selected` if it should appear in full on the Research page)
- **Remove a working paper**: delete its entry (or comment it out with `%`)

### 2. Preview locally (optional)

Build the site locally to check your changes before publishing:

```bash
quarto render
```

Then open `_site/index.html` in a browser to review.

### 3. Commit and push

```bash
git add -A
git commit -m "Brief description of what you changed"
git push origin main
```

Pushing to `main` triggers GitHub Actions, which renders the site and deploys it to GitHub Pages. The live site at [lnostbakken.github.io](https://lnostbakken.github.io) updates within a few minutes.

You can monitor the build at:
**https://github.com/lnostbakken/lnostbakken.github.io/actions**

## Repository structure

```
papers_all.bib        — single source of truth for all papers (use keywords to categorise)
index.qmd             — home page
about.qmd             — full bio page
cv.qmd                — CV page (positions, committees, publications)
research.qmd          — research page (auto-generated from papers_all.bib)
styles.css            — custom CSS
files/CV.pdf          — CV PDF (replace to update the download link)
files/LN_photo18.jpg  — profile photo
R/bib_helpers.R       — R functions that render bibliography entries
.github/workflows/    — GitHub Actions build-and-deploy workflow
```

---

## Notes

- **Papers are filtered by keyword**, not by which file they are in. `papers_all.bib` is the only bib file used.
- **Do not edit `_site/`** — this folder is auto-generated by `quarto render` and overwritten on each build.
- **GitHub Actions uses R and the `bib2df` package** to render the research page. If the build fails, check the Actions log linked above.
